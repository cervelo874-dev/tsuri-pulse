# ツリパルス（TsuriPulse）🎣⚡

場所を選ぶだけで「天気・風速・風向・潮の動き・釣れる時間・持ち物」がパッと見でわかる、釣り初心者にも優しい近未来ソナーダッシュボード（モバイルファーストPWA対応）。

## 主な機能
- **2テーマ・ワンタップ切替**：夜釣りでも眩しくない「ナイト／標準モード（🌙）」と、真昼の直射日光下でもくっきり見やすい「サンライトモード（☀️）」
- **6ジャンル精査版スコアエンジン**（`src/config/fishScoringConfig.ts`）：サビキ系・青物／サゴシ・チヌ／メジナ・根魚・タチウオ・アオリイカを1時間単位で評価＋安全ブレーカー（強風・高波・荒天時は30点上限ロック）＋狙い目TOP3バッジ＋初心者通訳パネル
- **日本全国34主要基準港のオフライン調和潮汐・月齢エンジン**：最寄り港を自動マッチングし、24時間タイドグラフ・満干潮・潮名（大潮〜若潮）を完全無料算出
- **横なぞりリアルタイム連動**：タイドグラフを指・マウスでスライドすると、選択時刻のスコア・ソナまるの表情・風向きコンパスが連動変化
- **AI相棒「ソナまる（SONA-01）」**：待ち時間ゼロのルールベース吹き出し＋「AI作戦会議」（Gemini API 3時間キャッシュ／キー未設定時は高精度戦術エンジンへ自動フォールバック）
- **全国フリー検索マップ・気象連動持ち物リスト・環境データ自動記録つき釣果ログ（写真自動圧縮・JSONバックアップ対応）**

## ローカル起動手順

```bash
cd tsuri-pulse
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

## ソナまる画像差し替え手順

`public/images/sonamaru/` に以下の5枚の透過PNGを配置するだけで自動反映されます（未配置時は5表情連動オリジナルSVGが自動描画されます）：

- `normal.png`（通常：スコア50〜79点）
- `excited.png`（爆釣チャンス：スコア80点以上）
- `caution.png`（警戒・心配：風速5m/s以上・雨・安全アラート）
- `analyzing.png`（レーダー分析中：ローディング・AI思考中）
- `celebration.png`（お祝い：釣果ログ保存時）
