# ソナまる（SONA-01）カスタム画像配置ガイド

このディレクトリ（`public/images/sonamaru/`）に以下のファイル名で透過PNG画像を配置すると、アプリ内のAI相棒「ソナまる」が自動的にオリジナル画像へ切り替わります（コード変更不要）。

## 対応ファイル名一覧（全5パターン）

| ファイル名 | 表示される条件 |
| :--- | :--- |
| `normal.png` | **通常表情**：スコア 50〜79点（穏やかな通常時） |
| `excited.png` | **爆釣チャンス表情**：スコア 80点以上（好条件・大チャンス時） |
| `caution.png` | **警戒・心配表情**：風速 5.0m/s以上、雨天、または安全ブレーカー作動時 |
| `analyzing.png` | **レーダー分析中表情**：気象データ取得中、または「AI作戦会議」思考中 |
| `celebration.png` | **お祝い表情**：釣果ログの保存完了直後 |

## 推奨画像仕様
- 形式：**背景透過 PNG**（正方形 `512×512px` 前後推奨）
- 未配置のファイルがある場合は、表情・発光色・玉ウキアンテナが連動する内蔵オリジナルSVGのソナまるへ自動的にフォールバック描画されます（1枚ずつ段階的に差し替えることも可能です）。
